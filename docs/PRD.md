## 1. 产品概述

### 1.1 一句话定位

一款**本地优先、以块为结构、所见即所得的 Markdown 桌面笔记软件**，用双向链接连接知识，用代码块与数学公式承载技术内容，用 Notion 式的留白与柔和观感降低书写阻力。

### 1.2 目标用户与核心场景

定位为**通用型笔记工具**，不预设单一职业人群。代码块与数学公式同等重要，均为一级公民。

| 场景 | 典型行为 | 对应能力 |
| --- | --- | --- |
| 日常记录 | 快速新建一篇笔记，想到哪写到哪，不关心保存 | 自动保存、块编辑、Markdown 快捷输入 |
| 技术笔记 | 粘贴代码、标注语言、折叠长片段、复制给他人 | 代码块高亮 / 行号 / 折叠 / 复制 |
| 学习推导 | 边写 LaTeX 边看公式成形，不打断思路 | KaTeX 块内原位编辑、即时渲染 |
| 知识串联 | 把新笔记挂到已有笔记上，回头能看到谁引用了我 | `[[双链]]`、块引用、反向链接面板 |
| 结构梳理 | 用多级分类整理，用标签横向聚合 | 无限层级文件夹、扁平标签多选过滤 |
| 全局回看 | 想看清知识之间的连接形态 | 关系图谱 |

### 1.3 设计原则

1. **正文即文件**：笔记正文永远是纯净、可被任何文本编辑器打开的 `.md` 文件，不做格式锁定。
2. **不分栏**：编辑器内部永远只有一栏。所见即所得即时渲染，不存在「左边源码 / 右边预览」的分割视图。
3. **块是最小单位**：每一段、每个公式、每段代码都是可被拖拽、折叠、引用、嵌入的独立块。
4. **少即是多**：Notion 式留白与柔和配色，无重阴影、无装饰性元素、无信息噪音。
5. **不出本机**：无账号、无云端、无遥测，断网 100% 可用。

### 1.4 术语表

| 术语 | 定义 |
| --- | --- |
| 笔记库（Vault） | 用户在磁盘上选定的一个文件夹，首版**仅支持单个库** |
| 笔记（Note） | 库内的一个 `.md` 文件，一篇笔记 = 一个文件 |
| 分类（Folder） | 库内的文件夹，可无限嵌套，一篇笔记只归属一个分类 |
| 块（Block） | 笔记内容的最小结构单元：段落、标题、列表项、代码块、公式块、引用块等 |
| 块 ID | 块的稳定标识符，**仅存于 SQLite 索引库，不写入 Markdown 正文** |
| 双向链接 | `[[笔记名]]`，正向可跳转，反向自动出现在目标笔记的反向链接面板 |
| 块引用 | `[[笔记名#^块ID]]`，精确指向某篇笔记中的某一个块 |
| 块嵌入 | `![[笔记名#^块ID]]`，把另一个块的内容内联显示在当前笔记中 |
| 反向链接 | 所有指向当前笔记（或当前块）的链接集合，含未链接提及 |
| 索引库 | 库内隐藏目录 `.easynote/index.db`，SQLite，存块结构、块 ID、链接关系、搜索索引 |
| 源码模式 | 整篇笔记切换为纯 Markdown 文本编辑视图，可随时切回所见即所得 |

## 2. 产品目标与衡量指标

| 目标 | 衡量方式 |
| --- | --- |
| 书写零打断 | 输入到渲染的延迟 ≤ 16ms；无需任何手动保存动作 |
| 数据可带走 | 用 VS Code / 记事本直接打开库内任意 `.md`，正文可读、无私有标签污染 |
| 代码与公式好用 | 公式输入过程中渲染实时跟随；代码块支持编辑器级手感（Tab、多光标） |
| 双链真的双向 | 任意笔记的反向链接面板 100% 覆盖库内全部显式引用 |
| 简约但不简陋 | 亮暗两套主题均通过 WCAG AA 正文对比度；界面无二级以上弹窗嵌套 |

## 4. 范围定义

### 4.1 首版范围内（In Scope）

- 单笔记库管理：首次启动选目录、设置中换库
- 无限层级文件夹（多级分类）、文件夹与笔记的增删改移重命名
- 笔记 CRUD，删除移入系统回收站
- 块级所见即所得编辑器：段落、标题、列表、任务列表、引用、分隔线、表格
- 代码块：高亮、行号、复制、语言切换、折叠、块内 Tab / 多光标 / 括号匹配
- 数学公式：行内 `$...$`、块级 `$$...$$`，KaTeX 块内原位编辑
- 块操作：拖拽排序、折叠展开、块菜单（转换类型 / 复制 / 删除 / 复制块链接 / 复制嵌入）
- 双向链接 `[[笔记名]]`、块引用 `[[笔记名#^块ID]]`、块嵌入 `![[...]]`
- 反向链接面板（含未链接提及）
- 关系图谱
- 扁平标签与多选过滤
- 基础搜索（标题 / 正文）+ Ctrl+K 快速跳转
- 大纲 TOC、字数统计
- 整篇源码模式切换
- 亮 / 暗 / 跟随系统三档主题
- 实时自动保存与保存状态指示
- 笔记内查找（Ctrl+F，属基础编辑器能力，若你希望移出首版请在评审时指出）

### 4.2 明确不做（Out of Scope）

| 不做的能力 | 说明 |
| --- | --- |
| 图片、视频附件 | 按你的要求排除，降级行为见 §7.4.5 |

### 5.2 核心流程

**首次启动**：欢迎页 → 「选择笔记库文件夹」（默认建议 `文档/EasyNote`，可改）→ 创建 `.easynote/` 隐藏目录并建立索引 → 生成一篇示例笔记（含标题、列表、代码块、公式、双链演示）→ 进入主界面，示例笔记处于打开状态。

**新建并书写**：Ctrl+N → 在当前选中文件夹下生成 `未命名.md` 并打开，标题自动进入重命名态 → 正文自动聚焦 → 输入即渲染，停笔约 500ms 自动落盘 → 状态栏短暂显示「已保存」。

**建立双链**：输入 `[[` → 弹出搜索浮层（标题模糊匹配 + 最近使用）→ 上下键选择、Enter 插入 → 渲染为可点击链接 → 目标笔记的反向链接面板立即新增一条。

**块嵌入**：在源笔记选中块 → 块菜单「复制块嵌入」→ 到目标笔记粘贴 → 生成 `![[源笔记#^块ID]]` → 渲染为内联只读内容块，顶部标注来源，点击跳转源位置。

**切换源码模式**：按源码切换快捷键 → 整篇变为 Markdown 文本编辑 → 修改后再次切换 → 重新解析并即时渲染。若源码存在无法解析的语法，切回时保留原文并在对应位置显示降级块，不丢字。

## 6. 信息架构与数据模型

### 6.1 库目录结构

```
用户选定的库目录/
├── .easynote/                # 应用隐藏目录，非笔记内容
│   ├── index.db              # SQLite 索引库：块结构、块 ID、链接、标签、搜索索引
│   └── tmp/                  # 原子写入临时文件、异常退出恢复草稿
├── 文件夹A/                  # 用户分类，可无限嵌套
│   ├── 子文件夹/
│   │   └── 笔记1.md
│   └── 笔记2.md
└── 未分类笔记.md
```

约束：

- `.easynote/` 由应用创建与维护，文件树默认不显示，用户在资源管理器中可见但不应手改。
- 除 `.easynote/` 外，库内结构 = 用户可见的分类结构，**一一对应磁盘真实目录**。
- 索引库随库目录一起移动；更换库路径后无需重建即可使用。
- 库内出现的非 `.md` 文件（图片、PDF 等）在文件树中不显示、不索引。

### 6.2 Markdown 正文规范

正文遵循 **CommonMark + GFM 子集**，不写入任何私有标记。

| 语法 | 支持 | 说明 |
| --- | --- | --- |
| `#` ~ `######` 标题 | 是 | 1–6 级 |
| 段落、硬换行 | 是 | 行尾两空格或反斜杠 |
| `**粗体**`、`*斜体*` | 是 | |
| `~~删除线~~` | 是 | GFM |
| `` `行内代码` `` | 是 | |
| 无序 / 有序列表、嵌套 | 是 | 缩进对应层级 |
| `- [ ]` 任务列表 | 是 | GFM |
| `>` 引用块 | 是 | 可嵌套 |
| 三反引号代码块 | 是 | 带语言标识 |
| `---` 分隔线 | 是 | |
| GFM 表格 | 是 | |
| `[文本](https://…)` 外部链接 | 是 | 仅允许 http / https / mailto |
| `$...$` 行内公式 | 是 | KaTeX |
| `$$...$$` 块级公式 | 是 | KaTeX |
| `[[笔记名]]` | 是 | 应用扩展语法 |
| `[[笔记名#^块ID]]` | 是 | 应用扩展语法，块 ID 为内部标识，见 R-01 |
| `![[笔记名#^块ID]]` | 是 | 应用扩展语法，块嵌入 |
| `#标签` | 是 | 行内标签，同时可在 frontmatter 中声明 |
| `![alt](path)` 图片 | **不渲染** | 降级行为见 §7.4.5 |
| 原生 HTML | **不渲染** | 按纯文本显示，安全约束见 §9 |
| `==高亮==`、脚注、上标下标 | **待确认** | 见 U-02 |
| Mermaid 代码块 | 不高亮为图表 | 按普通代码块处理，语言标识保留 |

frontmatter（可选，仅用于标签与标题别名）：

```yaml
---
tags: [前端, 读书笔记]
---
```

### 6.3 块模型

每个块在索引库中记录：

| 字段 | 说明 |
| --- | --- |
| block_id | 全局唯一，nanoid(12)，**仅存索引库** |
| note_id | 所属笔记 |
| ordinal | 块在笔记中的顺序 |
| type | paragraph / heading / list_item / task_item / quote / code / math / table / hr … |
| parent_block_id | 列表嵌套、引用嵌套时的父块 |
| plain_text | 纯文本内容，供搜索与未链接提及匹配 |
| content_hash | 归一化内容哈希，供变更匹配 |
| start_line / end_line | 在 `.md` 中的行号区间，供源码模式与跳转定位 |
| heading_level / code_lang | 类型附加属性 |
| collapsed | 折叠状态 |

**块 ID 按需分配**：未被任何链接引用的块不强制持久化 ID；一旦被执行「复制块链接 / 复制块嵌入」，立即分配并持久化，此后必须优先保证其稳定。

**块 ID 稳定性算法**（因正文不含 ID，这是 D-03 的直接代价）：

文件变更后按以下优先级重新匹配旧块：

1. `content_hash` 完全相同且顺序相对不变 → 直接复用 ID
2. 内容相近（归一化文本相似度高于阈值）且前后邻块哈希一致 → 复用 ID
3. 被引用块优先于普通块参与匹配，避免引用断裂
4. 匹配失败的旧 ID 标记为失效，对应链接转为「失效引用」状态，**不静默重指向其他块**

### 6.4 SQLite 表结构（索引库）

| 表 | 关键字段 | 用途 |
| --- | --- | --- |
| `vault_meta` | schema_version, last_scan_at | 索引版本与迁移 |
| `folders` | id, parent_id, name, path, sort_order | 多级分类 |
| `notes` | id, path, title, folder_id, created_at, modified_at, content_hash, size_bytes | 笔记元数据 |
| `blocks` | 见 §6.3 | 块结构与块 ID |
| `links` | id, source_note_id, source_block_id, target_note_id, target_block_id, link_type, raw_text, resolved | 正向链接，反向查询即反向链接 |
| `tags` | id, name | 扁平标签字典 |
| `note_tags` | note_id, tag_id | 笔记-标签多对多 |
| `notes_fts` | FTS5 虚表：title, plain_text | 基础搜索与未链接提及 |
| `file_state` | path, mtime, content_hash, last_indexed_at | 文件监听与增量索引 |

索引要求：`links(target_note_id)`、`links(target_block_id)`、`blocks(note_id, ordinal)`、`note_tags(tag_id)` 必须建索引，反向链接与标签过滤不允许全表扫描。

应用级设置（主题、窗口尺寸、库路径、快捷键）**不放入库内**，存于系统用户配置目录，避免换库时主题被带走。

### 6.5 链接解析规则

- `[[笔记名]]` 按**笔记标题**匹配：唯一命中直接解析；多个同名笔记时在链接上显示所在分类路径，点击弹出选择。
- 标题含 `#`、`[`、`]` 时按转义规则处理；重命名笔记时自动批量更新库内所有指向它的链接文本。
- `[[笔记名#^块ID]]`：先解析笔记，再在 `blocks` 表查块 ID；块已失效则显示「引用已失效」占位，提供「移除引用」与「跳回源笔记」。
- `![[...]]` 与上述解析一致，仅渲染形态不同。
- 失效链接一律保留原始文本，绝不静默删除。

### 6.6 文件与索引一致性

- 使用文件监听（chokidar）捕获外部修改：外部变更且本地无未保存内容 → 直接重载并重建该笔记索引。
- 外部变更且本地正在编辑 → 编辑区顶部出现非阻断横幅「文件已被外部修改」，提供「加载磁盘版本 / 保留当前版本」。
- 启动时全量扫描 + mtime 增量比对；提供「重建索引」手动入口。
- **重建索引不清空已有块 ID**，复用 §6.3 的匹配算法。
- 所有写入采用「临时文件 + 原子重命名」，杜绝半写文件。

## 7. 功能需求规格

### 7.1 应用外壳与布局

三栏结构，**编辑器内部永不分栏**：

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：面包屑 / 当前笔记标题        源码切换  主题  设置     │
├──────────┬──────────────────────────────────┬────────────┤
│          │                                  │            │
│  左侧边栏 │        编辑区（单栏）            │  右侧面板   │
│  文件树   │      内容居中，最大宽度          │ 反向链接 /  │
│  标签     │                                  │  大纲       │
│  搜索     │                                  │            │
│          │                                  │ （可收起）  │
├──────────┴──────────────────────────────────┴────────────┤
│ 状态栏：字数 / 字符 / 预计阅读时长           保存状态     │
└──────────────────────────────────────────────────────────┘
```

- 左侧边栏三个可切换视图：**文件树 / 标签 / 搜索**。因布局不含中间笔记列表栏，标签过滤结果与搜索结果均在侧边栏内呈现。
- 右侧面板两个 Tab：反向链接、大纲；可整体收起。
- 首版单笔记打开，无标签页、无分屏。

### 7.2 多级分类与文件树

- 文件夹无限嵌套，支持新建、重命名、删除、拖拽移动、右键菜单。
- 一篇笔记只能位于一个文件夹；拖拽到另一文件夹即真实移动磁盘文件，并同步更新库内相对路径引用。
- 文件夹支持折叠展开，展开状态记忆。
- 删除文件夹：内含笔记时弹窗说明数量，确认后整体移入系统回收站。
- 文件树支持按名称排序；空库显示引导空状态。

### 7.3 笔记管理

- 新建、重命名（F2）、移动、复制、删除。
- 重命名自动同步所有 `[[旧名]]` 链接文本。
- 删除弹窗明确文案「将移入系统回收站，可从系统回收站恢复」，确认后调用系统 API；系统回收站不可用时（如部分 Linux 环境）给出明确错误，不静默永久删除。
- 标题冲突：同文件夹下同名自动追加序号或提示，由用户选择。

### 7.4 块编辑器

#### 7.4.1 块类型

段落、H1–H6、无序列表、有序列表、任务列表、引用块、代码块、公式块、表格、分隔线、块嵌入块；行内节点含粗体、斜体、删除线、行内代码、行内公式、外部链接、双链、块引用。

#### 7.4.2 Markdown 快捷输入（输入即转换）

| 输入 | 结果 |
| --- | --- |
| `# ` … `###### ` | H1–H6 |
| `- ` / `* ` | 无序列表 |
| `1. ` | 有序列表 |
| `- [ ] ` | 任务项 |
| `> ` | 引用块 |
| ` ``` ` + 语言 + Enter | 代码块 |
| `$$` + Enter | 公式块 |
| `---` + Enter | 分隔线 |
| `**文本**` | 粗体（闭合即渲染） |
| `*文本*` / `~~文本~~` | 斜体 / 删除线 |
| `` `代码` `` | 行内代码 |
| `$公式$` | 行内公式 |
| `[[` | 双链搜索浮层 |
| `![[` | 块嵌入搜索浮层 |
| `/` | 块内插入菜单（段落 / 标题 / 列表 / 代码 / 公式 / 表格等） |

> `/` 插入菜单属于编辑器内块插入能力，**不是**被排除的全局命令面板。

#### 7.4.3 块操作

- 悬停块左侧显示拖拽手柄；拖拽可上下排序，可拖入 / 拖出列表层级。
- 块菜单：转换为（段落 / H1–H3 / 列表 / 任务 / 引用 / 代码 / 公式）、在下方插入、折叠展开、复制块链接、复制块嵌入、复制为 Markdown、删除块。
- 折叠：标题折叠其下内容至下一同级标题；代码块、公式块、引用块可单独折叠；折叠状态持久化在索引库。
- Alt+↑ / ↓ 移动当前块；Tab / Shift+Tab 调整列表缩进。
- 撤销 / 重做覆盖全部块操作。

#### 7.4.4 即时渲染

- 输入即渲染，无预览栏、无手动刷新。
- 光标所在块保留必要的源码可见性（如链接文本、公式 LaTeX），离开即恢复纯渲染态。
- 渲染失败（如 KaTeX 语法错误）显示原始文本 + 轻量错误提示，不阻塞其他块。

#### 7.4.5 不支持语法的降级

- 图片 `![alt](path)`：显示为带图标的占位行「图片附件暂不支持：alt」，保留原始 Markdown，不删除、不请求资源。
- 原生 HTML：按纯文本显示，不解析、不执行。
- 未知 fenced 语言：按纯文本代码块显示，语言标识保留。

### 7.5 代码块

- 语法高亮、行号、右上角语言下拉切换、一键复制按钮。
- 折叠 / 展开：折叠后保留首行与语言标识，显示行数。
- 块内编辑手感：Tab / Shift+Tab 缩进、多光标、括号匹配、自动闭合。
- 语言清单覆盖主流语言（JS / TS / Python / Java / Go / Rust / C / C++ / C# / SQL / Shell / HTML / CSS / JSON / YAML / Markdown / LaTeX 等），支持纯文本。
- 亮暗主题切换时代码高亮配色同步切换。
- Mermaid 语言不做图形渲染。

### 7.6 数学公式

- 行内 `$...$` 与块级 `$$...$$`，KaTeX 渲染。
- **块内原位编辑**：公式块获得焦点时，在**同一个块内**展开 LaTeX 输入行，其下方为实时渲染结果；输入过程中渲染持续更新；失焦后输入行收起，仅保留渲染结果。
- 行内公式同样在原位置展开编辑，不弹窗、不分栏。
- KaTeX 不支持的命令：显示错误提示并保留 LaTeX 原文，不空白、不崩溃。
- 提供常用公式示例插入（分数、求和、积分、矩阵），通过 `/` 菜单进入。

### 7.7 双向链接

- 输入 `[[` 弹出搜索浮层：标题模糊匹配、最近使用置顶、支持「创建名为 X 的新笔记」。
- 渲染为可点击链接，Ctrl+点击或单击跳转（编辑态与阅读态行为在 UI 评审时确认，见 U-06）。
- 指向不存在笔记的链接显示为「未创建」样式，点击创建。
- 重命名目标笔记时链接文本自动更新。

### 7.8 块引用与块嵌入

- 块菜单「复制块链接」生成 `[[笔记名#^块ID]]`，粘贴后渲染为指向该块的链接，点击跳转并高亮目标块。
- 「复制块嵌入」生成 `![[笔记名#^块ID]]`，渲染为内联只读内容块：显示源块内容、顶部来源标注、点击跳转。
- 嵌入块为**只读镜像**：源块更新后嵌入处同步刷新；不支持在嵌入处直接编辑源内容。
- 同一笔记内自嵌入、循环嵌入需检测并提示，不无限递归渲染（最大嵌套深度 3 层）。
- 源块失效时显示「引用已失效」占位与原始文本。

### 7.9 反向链接面板

右侧面板默认 Tab，分两组：

- **已链接提及**：列出所有指向当前笔记 / 块的来源，含来源笔记标题、上下文片段、块级引用标识；点击跳转。
- **未链接提及**：正文中出现当前笔记标题但未加链接的位置；每条提供「转为链接」操作，支持逐条或全部转换。

面板实时更新，空时显示「暂无反向链接」。

### 7.10 关系图谱

- 全局图谱：节点 = 笔记，边 = 链接关系；力导向布局，Canvas 渲染。
- 局部图谱：以当前笔记为中心的 N 度邻居（N 可调，默认 1）。
- 交互：缩放、平移、拖拽节点、悬停高亮邻居、点击打开笔记、孤立节点可隐藏。
- 节点大小随链接数量变化；节点着色维度见 U-03。
- 性能降级：节点数超过阈值时提示并默认聚合 / 限制渲染，保证帧率。

### 7.11 标签

- 扁平标签，无层级。来源：正文 `#标签` 或 frontmatter `tags`。
- 侧边栏「标签」视图：标签列表 + 各标签笔记数；支持多选，多选时提供 AND / OR 切换。
- 过滤结果以列表呈现于侧边栏，点击打开笔记。
- 标签重命名 / 删除在标签视图右键完成，重命名批量更新正文与 frontmatter。

### 7.12 搜索与快速跳转

- **基础搜索**：Ctrl+Shift+F 聚焦侧边栏搜索视图，对标题与正文做关键词搜索（SQLite FTS5），结果含标题、命中高亮片段、所在分类；点击打开并定位。
- **快速跳转**：Ctrl+K 弹出居中浮层，按标题模糊匹配 + 最近打开排序，纯键盘可完成跳转。
- **笔记内查找**：Ctrl+F，当前笔记内查找替换。
- 不含命令执行、不含标签 / 时间筛选语法。

### 7.13 大纲与字数统计

- 右面板「大纲」Tab：按标题层级生成 TOC，点击跳转，当前位置高亮。
- 状态栏：字数、字符数（不含空白）、预计阅读时长。
- 字数口径：CJK 字符按字计，非 CJK 按单词计；阅读速度常量见 U-04。
- 代码块与公式 LaTeX 源码默认不计入正文字数（若你希望计入，请在评审时指出）。

### 7.14 源码模式

- 快捷键整篇切换为 Markdown 文本编辑视图，再次切换返回所见即所得。
- 源码视图提供等宽字体、行号、基础语法着色。
- 切回时重新解析：合法语法正常渲染，非法语法按 §7.4.5 降级，**任何情况下不丢失字符**。
- 源码模式与所见即所得共享同一份内容，不存在两份副本。

### 7.15 主题与外观

- 三档：亮色 / 暗色 / 跟随系统，顶栏可切换，设置中可修改。
- 跟随系统时监听系统主题变化并实时响应。
- 配色固定，不提供自定义强调色、不提供自定义 CSS。
- 主题切换覆盖：界面、编辑器、代码高亮、公式、图谱、滚动条。

### 7.16 自动保存与状态指示

- 停笔约 500ms 自动写入磁盘，原子写入；无保存按钮。
- 状态栏三态：编辑中（未落盘）/ 已保存 / 保存失败（附重试）。
- Ctrl+S 作为「立即写入」保留，不创建任何历史快照。
- 异常退出最多丢失一个防抖窗口的输入；启动时检测 `.easynote/tmp` 中未完成写入并提示恢复。

### 7.17 设置

库路径更换、主题、字号、快捷键查看、索引重建、关于。设置项存于系统用户配置目录。

## 9. 非功能需求

### 9.1 性能

| 指标 | 目标 |
| --- | --- |
| 冷启动（1000 笔记库，SSD） | ≤ 2s |
| 打开笔记（10 万字内） | ≤ 150ms |
| 输入渲染延迟 | ≤ 16ms；5000 块大文档 ≤ 32ms |
| 自动保存落盘 | ≤ 100ms |
| 全局搜索（1 万笔记） | ≤ 300ms |
| 首次全量索引（1 万笔记） | ≤ 30s，可后台进行 |
| 增量索引 | ≤ 200ms / 文件 |
| 图谱（2000 节点） | ≥ 30fps，超出自动降级 |
| 常驻内存（1000 笔记库，单笔记打开） | ≤ 500MB |
| 长列表 | 文件树、搜索结果、反向链接均虚拟滚动 |

### 9.2 可靠性与数据安全

- 所有写盘原子化，异常断电不产生半文件。
- 解析失败、渲染失败、KaTeX 错误均不得导致内容丢失或应用崩溃。
- 失效引用保留原文，不静默改写。
- 索引损坏可从 `.md` 重建；但索引库整体丢失会导致块级引用失效，见 R-02。

### 9.3 隐私与安全

- 完全离线，无账号、无遥测、无后台上传。
- 渲染进程禁用 Node 集成，启用上下文隔离与沙箱，preload 仅暴露白名单 API。
- 不渲染原生 HTML，防 XSS。
- 外部链接仅允许 http / https / mailto，经系统默认浏览器打开，打开前可提示。
- SQLite 访问与文件系统操作集中在主进程。

### 9.4 可访问性

全键盘可达、焦点可见、正文对比度 AA、尊重减少动效、主要控件提供 aria 标签。

### 9.5 兼容性

Windows 10+、macOS 12+、主流 Linux 发行版（AppImage / deb）。安装包与签名公证见 U-05。

### 9.6 国际化

见 U-07（首版界面语言待你确认），文案需集中管理，不硬编码在组件内。

## 10. 技术架构约束

以下为已确认选型的落地约束，非新增产品决策。

| 层 | 职责 |
| --- | --- |
| Electron 主进程 | 窗口、库目录与文件 IO、SQLite（better-sqlite3）、文件监听、系统回收站、原生对话框与菜单、系统主题监听 |
| Preload | contextBridge 白名单 API，隔离渲染进程 |
| 渲染进程 | Vue 3 + TypeScript UI、Tiptap 2 编辑器、KaTeX、代码块编辑、图谱 Canvas |

- **编辑器**：Tiptap 2（ProseMirror），自定义节点：代码块、公式块、公式行内、双链、块引用、块嵌入；自定义 Markdown 解析器 / 序列化器，保证 §6.2 语法的**无损往返**。
- **代码块内部编辑**：需要 Tab 缩进、多光标、括号匹配，建议在代码块节点内嵌 CodeMirror 6（具体引擎见 U-08）。
- **IPC 通道**：vault / note / folder / block / link / tag / search / index / settings / theme / trash 分组，全部走类型化定义。
- **索引与渲染分离**：索引库只在主进程读写，渲染进程不直接持有数据库连接。

## 13. 风险与未决事项

### 13.1 风险

| 编号 | 风险 | 影响 | 应对 |
| --- | --- | --- | --- |
| R-01 | **块 ID 不进正文，但链接文本含 `#^块ID`** | 这些链接在 Obsidian 等其他工具中无法解析到块（笔记级 `[[笔记名]]` 仍可被识别）。这是 D-03 + D-13/D-14 组合的必然代价 | 已在 §6.5 记录；若你不能接受，需重新决策块 ID 存储方式 |
| R-02 | 索引库整体丢失或损坏 | 块 ID 无法恢复，块级引用与嵌入失效（笔记正文不受影响） | 提供索引重建；建议用户备份时包含 `.easynote/`；是否增加块 ID 冗余备份见 U-09 |
| R-03 | 块 ID 稳定性依赖匹配算法 | 外部编辑器大幅改动、块复制粘贴、块重排后可能误匹配 | M0 必须先验证；被引用块优先匹配；匹配失败一律标失效而非错指 |
| R-04 | **首版无应用内回收站、无版本历史，且实时自动保存** | 「删除」可靠系统回收站恢复，但「误改 / 误覆盖」无任何回退手段 | 需你确认是否接受，见 U-10 |
| R-05 | Tiptap 2 与 Markdown 的无损往返 | 双链、公式、表格等扩展语法易在序列化时丢失 | M0 建立全语法往返测试集，作为后续回归门槛 |
| R-06 | 大库性能 | 万级笔记的索引、搜索、图谱可能不达标 | 增量索引、FTS5、虚拟滚动、图谱降级 |
| R-07 | 无附件能力但用户粘贴图片 | 用户预期与实际行为不符 | 粘贴图片时给出明确「不支持图片附件」提示，不静默丢弃 |
