# EasyNote UI 设计规范

| 版本 | 1.0 |
| --- | --- |
| 依据 | PRD v1.0 §7.1、§8；技术栈基线 2026-11-09 |
| 范围 | 首版桌面端 |
| 冲突处理 | 功能范围以 PRD 为准；视觉、布局、组件、文案以本文为准 |

## 0. 硬约束

- 单栏编辑。任何界面状态下都不出现源码 / 预览并排。
- 三栏外壳：左树、中编辑、右面板。面板开合推挤内容，不覆盖编辑区。
- Electron 无边框窗口：顶栏即自定义标题栏。Windows / Linux 不使用原生标题栏、原生菜单栏与原生窗口按钮。
- 同一信息只出现一次：标题在正文首行，路径在顶栏，字数在状态栏，保存状态在状态栏。
- 每个视图最多一个主按钮。其余操作进右键菜单、块菜单或“更多”菜单。
- 正文区不显示功能介绍、操作教程、快捷键提示、营销文案。
- 不新增 PRD 之外的入口：导入导出、模板、AI、命令面板、附件、多标签页、云同步。

## 1. 视觉基调

- 关键词：平面、留白、低对比边界。
- 层级只用三种手段：背景色差、1px 边框、字号 / 字重。不用阴影区分层级。
- 阴影只用于菜单、浮层、对话框。正文区无卡片堆叠。
- 颜色只表达语义：强调色用于链接、选中、焦点；红色只用于删除与失败；橙色只用于警告。
- 图标统一 16px 线性图标，1.5px 描边，`currentColor`；全部使用开源 Lucide 图标库（`@lucide/vue`），不用 emoji、不用彩色图标。
- 不使用渐变、玻璃拟态、发光、彩色阴影、3D、装饰插画。

## 2. 布局系统

### 2.1 应用外壳

```
┌──────────────────────────────────────────────────────────────────────┐
│ 44  [≡] 库 / 分类 / 子分类         [源码] [主题] [设置] [▤]  —  □  × │
├───────────────┬──────────────────────────────────┬───────────────────┤
│ 260           │                                  │ 300               │
│ 文件 标签 搜索 │  H1 笔记标题（正文内，可编辑）    │ 反向链接 | 大纲   │
│ ───────────── │                                  │ ───────────────── │
│ 新建        ⋯ │  正文 max 720，水平居中           │                   │
│               │                                  │                   │
│ 文件树         │                                  │ 面板内容          │
│               │                                  │                   │
│ [图谱]        │                                  │                   │
├───────────────┴──────────────────────────────────┴───────────────────┤
│ 24  1,234 字 · 1,056 字符 · 约 4 分钟                   ● 已保存      │
└──────────────────────────────────────────────────────────────────────┘
```

| 区域 | 尺寸 | 规则 |
| --- | --- | --- |
| 顶栏 | 44px | 固定；同时是自定义标题栏与拖拽区 |
| 窗口控制 | 46 × 44 | Windows / Linux 自绘；macOS 使用系统交通灯，不绘制右侧按钮 |
| 左侧边栏 | 260px，可拖 200–400px | 可收起为 0，拖拽手柄热区 8px |
| 右侧面板 | 300px，可拖 240–480px | 可收起为 0 |
| 编辑区 | 内容最大宽度 720px | 水平居中，单栏 |
| 状态栏 | 24px | 固定 |
| 窗口最小 | 1024 × 680 | 低于此尺寸不保证布局 |

### 2.2 断点与默认开合

| 窗口宽度 | 默认状态 | 内容左右留白 |
| --- | --- | --- |
| ≥ 1440px | 左右面板都展开 | 96px |
| 1200–1439px | 右面板收起，左栏展开 | 48px |
| < 1200px | 左栏展开，右栏收起 | 24px |

用户手动开合后覆盖默认值，记忆到应用设置。

### 2.3 操作归属

| 区域 | 只放这些操作 | 不放 |
| --- | --- | --- |
| 顶栏 | 侧栏开关、面包屑、源码切换、主题、设置、右栏开关、窗口控制 | 新建、搜索、图谱、导入导出、帮助、应用名 / 窗口标题 |
| 文件树头部 | 新建（笔记 / 文件夹）、更多（按名称排序、折叠全部） | 标签、搜索、设置 |
| 文件树条目 | 打开、展开、拖拽移动、右键菜单、F2 重命名 | 编辑正文、切换主题 |
| 标签视图 | 多选过滤、AND / OR、清除；右键重命名 / 删除 | 新建标签、标签层级 |
| 搜索视图 | 关键词输入、结果列表 | 标签 / 时间筛选、命令执行 |
| 编辑区 | 拖拽手柄、块菜单、`/` 插入菜单、`[[` 链接浮层、块内编辑 | 全局导航、文件管理 |
| 右侧面板 | Tab 切换、收起、反向链接条目操作、大纲跳转 | 编辑、删除笔记 |
| 状态栏 | 保存失败时重试 | 主题、设置、字数点击 |
| 图谱 | 图谱工具栏（全局 / 局部、深度、隐藏孤立、适应窗口、返回） | 文件操作 |
| 设置 | 库路径、主题、字号、快捷键、索引重建、关于 | 编辑器内容操作 |

原则：动作跟着对象走。文件动作在文件树，标签动作在标签视图，块动作在块菜单。顶栏只做全局壳层控制。

### 2.4 Electron 自定义标题栏

主窗口无边框，顶栏与标题栏合并为同一条 44px 区域。禁止使用 Windows 原生标题栏、原生菜单栏与原生窗口按钮。

| 平台 | BrowserWindow | 标题栏表现 |
| --- | --- | --- |
| Windows | `frame: false`、`thickFrame: true`、`titleBarOverlay: false` | 右侧自绘最小化 / 最大化 / 关闭 |
| Linux | `frame: false` | 同上；窗口阴影由窗口管理器决定 |
| macOS | `titleBarStyle: 'hiddenInset'` | 保留系统交通灯，左侧预留 78px；不绘制右侧按钮 |

- Windows / Linux 调用 `Menu.setApplicationMenu(null)`，移除原生菜单栏；macOS 只保留屏幕顶部系统菜单，窗口内无菜单栏。
- `titleBarOverlay` 必须关闭；不得回退到 Windows 原生 caption 按钮。
- 拖拽：顶栏空白与不可点击的面包屑文本使用 `-webkit-app-region: drag`；所有按钮、可点击面包屑、窗口控制使用 `no-drag`。
- 双击拖拽区切换最大化 / 还原；拖拽已最大化的窗口时由系统恢复并移动。
- 窗口控制组固定在顶栏最右侧，紧贴窗口边缘，顺序为最小化、最大化 / 还原、关闭；每个 46 × 44，图标 12px 线性，关闭图标 10px。
- 悬停：最小化 / 最大化 `bg-hover`；关闭 `danger` 底 + 白色图标。按下：最小化 / 最大化 `bg-selected`；关闭 `danger-active`。
- 窗口控制无圆角、无边框、无 Tooltip；提供 `aria-label`：“最小化”“最大化”“还原”“关闭”。
- 最大化后图标切换为还原；窗口贴边、分屏、缩放时按钮位置不变。
- Windows 使用 `thickFrame: true` 保留系统缩放边缘与 Aero Snap；禁止 CSS 自绘缩放条。
- Windows 11 的 Snap Layouts 悬停菜单依赖原生最大化按钮，自绘后不可用；首版接受该取舍，不做自定义补偿。
- 窗口外阴影与圆角由系统窗口管理器控制，CSS 不模拟。
- 顶栏不显示应用名、笔记标题或窗口标题；左侧仍为侧栏开关 + 面包屑。
- macOS 顶栏左侧内边距 78px，交通灯区域不放置任何可点击元素。

### 3.4 间距、圆角、描边、阴影、动效

| 项 | 规范 |
| --- | --- |
| 间距 | 4px 网格：4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 圆角 | 输入框、按钮、树行 4px；菜单、浮层、代码块 6px；对话框 8px |
| 描边 | 默认 1px；焦点环 2px；拖拽插入线 2px |
| 阴影 | 仅菜单 / 浮层 / 对话框：亮色 `0 4px 12px rgba(0,0,0,.08)`，暗色 `0 4px 12px rgba(0,0,0,.40)` |
| 悬停动效 | 120ms ease-out，只变背景色 / 文字色 |
| 面板开合 | 180ms ease-out，改变宽度，不淡入淡出 |
| 主题切换 | 200ms ease-out，仅颜色过渡 |
| 减少动态效果 | 系统开启后全部时长设为 0，不做缩放、位移、淡入 |

不使用弹跳、缩放、视差、自动播放动画。

## 4. 基础组件

### 4.1 尺寸速查

| 组件 | 尺寸 |
| --- | --- |
| 图标按钮 | 28 × 28，图标 16 |
| 小按钮 | 28 高，左右内边距 10 |
| 默认按钮 | 32 高，左右内边距 12 |
| 输入框 / 下拉框 | 32 高，左右内边距 8 |
| 菜单项 | 28 高，左右内边距 8 |
| 树行 / 标签行 | 28 高 |
| 右栏列表行 | 最小 32 高 |
| Tab | 32 高 |
| 对话框 | 确认 400 宽；设置 560 宽 |
| 快速跳转 | 520 宽 |
| 链接 / 块浮层 | 320 宽 |
| 滚动条 | 10 宽，圆角 5 |

### 4.2 状态规则

| 状态 | 规则 |
| --- | --- |
| 默认 | 无阴影、无渐变 |
| 悬停 | `bg-hover`，120ms |
| 聚焦 | 1px `accent` 边框 + 2px `focus-ring` 外环；键盘可见 |
| 激活 / 选中 | `bg-selected`，文字 `text-primary`，必要时文字 `accent` |
| 禁用 | 透明度 0.4，光标 `not-allowed`，不响应悬停 |
| 加载 | 14px 旋转图标，保留原文字与宽度，不跳布局 |
| 错误 | 1px `danger` 边框 + 12px `danger` 说明；不抖动、不弹窗 |

### 4.3 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 | 32 高，`accent` 底，白字，13px/500，圆角 4 | 每个视图最多 1 个；对话框确认 |
| 次按钮 | 32 高，透明底，1px `border-strong`，`text-primary` | 次要确认 |
| 幽灵按钮 | 28 高，无边框，悬停 `bg-hover` | 取消、工具操作 |
| 危险按钮 | 32 高，`danger` 底，白字；悬停 `danger-hover`，按下 `danger-active` | 仅删除确认对话框 |
| 文字按钮 | 13px，`accent`，悬停加下划线 | 行内“转为链接”“重试” |
| 图标按钮 | 28 × 28，图标 16 | 顶栏、面板头、代码块 |

按钮文案 2–5 个字，动词开头，不加句号。禁止图标 + 长文案堆叠。

### 4.4 输入框与选择

- 输入框：32 高，1px `border-strong`，`bg-app`，13px，圆角 4。占位文字 `text-tertiary`。
- 搜索框：左侧 16px 搜索图标，左内边距 30；有内容时右侧出现 16px 清除按钮。
- 行内重命名：24 高，无边框，`bg-app`，1px `accent` 聚焦边框，全选当前文字。
- 复选框：14 × 14，圆角 3；选中 `accent` 底 + 白色勾。
- 单选：14 × 14；选中 `accent` 圆点。
- 开关：28 × 16，圆角 8；开启 `accent`。
- 分段控制：28 高，`bg-sidebar` 底，内边距 2，圆角 4；选中项 `bg-app` + 1px `border` + `text-primary`。

### 4.5 菜单与浮层

- 菜单：`bg-elevated`，1px `border`，圆角 6，内边距 4，阴影；最小宽 180，最大宽 320。
- 菜单项：28 高，内边距 0 8，图标 16 + 间距 8，文字 13；快捷键右对齐 12px `text-tertiary`。
- 危险菜单项：文字 `danger`，悬停底色 `rgba(235,87,87,0.08)`。
- 分隔线：1px `border`，上下外边距 4。
- 子菜单：仅一层，右侧展开，间距 4。
- 同一时间只开一个菜单 / 浮层；Esc 或点击外部关闭。
- 位置自动翻转，距窗口边缘至少 8px。
- Tooltip：12px，内边距 4 8，圆角 4，延迟 400ms，最大宽 240；用于解释图标按钮，不复述可见文字；窗口控制按钮除外。

### 4.6 对话框与提示

- 对话框：`bg-elevated`，1px `border`，圆角 8，阴影，内边距 20；标题 15px/600，正文 13px/1.6，底部按钮右对齐，间距 8。
- 遮罩：`backdrop`；点击遮罩等同取消，Esc 关闭。
- 禁止二级以上弹窗嵌套。设置里的快捷键用行内展开，不再开第二层。
- Toast：底部居中，距状态栏 24，`bg-elevated` + 1px `border`，圆角 6，内边距 8 12，12px，最长 360，3 秒自动消失；错误 5 秒。
- Toast 只用于“已复制”“不支持图片附件”等非阻断反馈。保存成功不弹 Toast。

### 4.7 Tab、树行、标签

- 左侧视图切换：三等分 Tab，32 高，图标 16 + 文字 13；选中 `bg-selected` + `text-primary`，未选中 `text-secondary`。
- 右侧面板 Tab：32 高，文字 13；选中 `text-primary` + 2px `accent` 下边框。
- 树行：28 高，圆角 4，内边距 0 6；每级缩进 16；文件夹箭头 16，展开旋转 90°；图标 16；文字 13.5，超长省略。
- 树行选中：`bg-selected`；悬停：`bg-hover`；焦点：内嵌 2px `focus-ring`。
- 拖拽：插入线 2px `accent`；拖入文件夹时整行 `bg-selected`；拖拽副本透明度 0.9。
- 标签行：28 高，14px 复选框 + `#` 12px `text-tertiary` + 名称 13.5 + 计数 12px `text-tertiary`。
- 标签选中：`bg-selected`，名称 `text-primary`；不额外加胶囊边框。

### 4.8 滚动条与分隔线

- 滚动条 10px，轨道透明，滑块 `border-strong`，圆角 5；悬停 `text-tertiary`。
- 分隔线 1px `border`，不叠加阴影，不做渐变。
- 长列表（文件树、搜索结果、反向链接）虚拟滚动，不显示分页。

### 5.1 首次启动 / 选择笔记库


- 首次索引 / 重建索引：顶栏底部 2px `accent` 进度线；状态栏右侧“正在建立索引 42%”；文件树与搜索结果用 32 高骨架行，不显示全屏加载。

## 7. 文案规范

- 陈述、具体、动词开头。按钮 2–5 字，不加句号。
- 正文句子用中文全角标点；按钮、标签、菜单项末尾不加标点。
- 错误文案 = 发生了什么 + 怎么办。例：“无法写入文件，请检查磁盘空间后重试。”
- 禁止营销词：智能、高效、一站式、轻松、开启、之旅、欢迎使用、强大、极致。
- 禁止在界面正文出现功能介绍、使用教程、快捷键大全、示例说明。
- 快捷键只出现在菜单右侧、Tooltip、设置快捷键表三处，不写进正文。
- 同一信息只保留一处：
  - 标题：正文首行。
  - 路径：顶栏面包屑。
  - 字数 / 字符 / 阅读时长：状态栏。
  - 保存状态：状态栏。
  - 标签：标签视图与正文语法，不在编辑区顶部重复。
- 删除按钮写结果：“移入回收站”，不写“确定删除”。
- 空状态只写一句说明，不写第二段解释。
- 所有文案集中管理，不在组件内硬编码；首版仅简体中文（待 U-07 确认后再扩展）。

## 8. 交互与可访问性

- 焦点顺序：顶栏 → 左侧边栏 → 编辑区 → 右侧面板 → 状态栏。对话框内焦点锁定，关闭后回到触发按钮。
- 窗口控制按钮进入顶栏焦点顺序，Tab 可聚焦，Enter / Space 激活；Alt+F4 关闭窗口。
- 所有悬停才出现的操作必须另有键盘或右键入口：块手柄、未链接提及“转为链接”、代码块复制 / 折叠。
- 点击热区最小 24 × 24；主按钮 32 高；树行整行可点。
- Esc 关闭最上层浮层；浮层关闭后恢复原焦点。
- 拖拽阈值 4px，避免误触点击。
- 编辑区光标 `text`；可点击元素 `pointer`；图谱节点 `grab`；禁用 `not-allowed`。
- 尊重系统“减少动态效果”；关闭后所有过渡为 0。
- 正文对比度 AA；焦点环在亮暗主题都可见；不以颜色作为唯一状态提示（保存状态同时有文字）。
- 文件树、搜索结果、反向链接虚拟滚动；面板开合不改变滚动位置。

## 9. 禁止清单

1. 渐变、玻璃拟态、发光、彩色阴影、3D、装饰插画。
2. 大圆角卡片、悬浮圆形主按钮、胶囊导航、卡片套卡片。
3. Emoji 或彩色插画充当功能图标。
4. 在正文、空状态、侧栏顶部放功能介绍、卖点、教程、快捷键大全。
5. 把新建、搜索、图谱、设置、导入导出全堆在顶栏。
6. 重复展示标题、路径、字数、保存状态、标签。
7. 添加 PRD 之外的入口：导入导出、模板、AI、命令面板、附件、多标签页、云同步。
8. 使用“智能 / 高效 / 一站式 / 轻松 / 开启知识之旅”等文案。
9. 滥用彩色徽章、药丸标签；标签只代表用户标签。
10. 给普通按钮加阴影、渐变或多重图标；每个视图出现两个以上主按钮。
11. 自动弹出引导、Tour、Tips、更新公告。
12. 改变编辑器单栏结构，或加入源码 / 预览分栏。
13. 用动画表达状态变化；除悬停、面板、主题外不加动效。
14. 在正文顶部重复显示文件名、路径、标签、字数。
15. 使用 Windows 原生标题栏、原生菜单栏或 `titleBarOverlay` 原生按钮。
16. 在顶栏显示应用名 / 窗口标题，或把应用按钮塞进窗口控制组。

## 10. 验收清单

- [ ] 三栏尺寸、最小窗口、断点与默认开合符合 §2。
- [ ] Windows / Linux 为 `frame: false`、`titleBarOverlay: false`，原生菜单栏已移除；macOS 使用 `hiddenInset` 且交通灯区域无遮挡。
- [ ] 顶栏拖拽区与 `no-drag` 交互元素划分正确，双击可最大化 / 还原。
- [ ] 窗口控制 46 × 44，最大化 / 还原图标切换，关闭悬停 `danger`；窗口缩放由系统边缘处理。
- [ ] 窗口控制按钮有 `aria-label`，Tab 可聚焦，Enter / Space 生效。
- [ ] 每个区域的入口与 §2.3 操作归属一致，无越权按钮。
- [ ] 亮暗两套 Token 全量落地，正文对比度 ≥ 4.5:1。
- [ ] 按钮、输入框、菜单、树行、Tab、对话框均覆盖默认 / 悬停 / 聚焦 / 选中 / 禁用 / 加载 / 错误。
- [ ] 每个页面最多一个主按钮；次要操作在右键菜单、块菜单或“更多”中。
- [ ] 空状态为一句说明 + 一个动作，无插画、无第二段解释。
- [ ] 正文区无功能介绍、教程、快捷键提示、重复元信息。
- [ ] 首次启动无账号、无功能列表、无引导弹窗。
- [ ] Ctrl+K、Ctrl+Shift+F、Ctrl+F、F2、Esc、方向键全键盘可用，焦点可见。
- [ ] 悬停操作均有键盘或右键替代入口。
- [ ] 减少动态效果开启后无过渡动画。
- [ ] 长列表虚拟滚动，面板开合不覆盖编辑区。
- [ ] 图谱在 2000 节点下按 §5.12 降级。
- [ ] 禁止清单逐条检查通过。
